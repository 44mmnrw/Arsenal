📚 Управление историей клуба - Краткая инструкция

## ✅ Установка

1. Таблица уже создана автоматически при запуске install-history-table.php
2. Классы подключены в главный файл плагина arsenal-team-manager.php
3. Меню доступно в админ-панели: Арсенал → История клуба

## 🎯 Как использовать

### Добавить новую запись истории

1. Перейти: **Арсенал** → **История клуба**
2. Нажать кнопку **"Добавить запись"**
3. Заполнить форму:
   - **Название главной секции** - например: "История клуба"
   - **Описание** - основной текст истории
   - **Временная шкала (JSON)** - события по годам
   - **Название второй секции** - например: "Рекорды и достижения"
   - **Рекорды (JSON)** - достижения клуба
   - **Достижения (JSON)** - медали и титулы
   - **Название третьей секции** - например: "Домашние стадионы"
   - **Дополнительные карточки (JSON)** - информация о стадионах
4. Нажать **"Создать запись"**

### Редактировать запись

1. В списке нажать **"Редактировать"** рядом с нужной записью
2. Изменить необходимые поля
3. Нажать **"Обновить запись"**

### Удалить запись

1. В списке нажать **"Удалить"** рядом с записью
2. Подтвердить удаление

## 💾 Структура JSON-данных

### Пример временной шкалы:
```json
[
  {"year": 2018, "event": "Основание клуба"},
  {"year": 2021, "event": "Чемпион Первой лиги"},
  {"year": 2023, "event": "Чемпион Первой лиги"}
]
```

### Пример рекордов:
```json
[
  {"name": "Чемпион Второй лиги", "year": 2019},
  {"name": "Двукратный чемпион Первой лиги", "years": "2021, 2023"}
]
```

### Пример достижений:
```json
[
  {
    "title": "Титулы",
    "items": [
      "Двукратный чемпион Первой лиги (2021, 2023)",
      "Чемпион Второй лиги (2019)"
    ]
  }
]
```

### Пример стадионов:
```json
[
  {"name": "РЦОП-Стайки", "location": "Минск", "capacity": "1,500"},
  {"name": "Городской стадион", "location": "Борисов", "capacity": "5,402"}
]
```

## 📊 Таблица БД

```
Таблица: wp_arsenal_history

Поля:
- id (INT) - уникальный ID
- title (VARCHAR 255) - заголовок
- description (LONGTEXT) - описание
- scale (JSON) - временная шкала
- title_second (VARCHAR 255) - заголовок 2
- records (JSON) - рекорды
- achievements (JSON) - достижения
- title_third (VARCHAR 255) - заголовок 3
- additional_cards (JSON) - карточки
- created_at (TIMESTAMP) - дата создания
- updated_at (TIMESTAMP) - дата обновления
```

## 🎯 Использование в PHP коде

```php
<?php

// Получить все записи
$history_records = Arsenal_History_Manager::get_all();

// Получить одну запись
$history = Arsenal_History_Manager::get_by_id( 1 );

if ( $history ) {
    echo $history->title;
    
    // Декодировать JSON
    $achievements = json_decode( $history->achievements, true );
    print_r( $achievements );
}

// Создать новую запись
$data = [
    'title' => 'История клуба',
    'description' => 'Текст...',
    'scale' => json_encode( [] ),
    'title_second' => 'Рекорды',
    'records' => json_encode( [] ),
    'achievements' => json_encode( [] ),
    'title_third' => 'Стадионы',
    'additional_cards' => json_encode( [] )
];

$new_id = Arsenal_History_Manager::create( $data );

// Обновить запись
Arsenal_History_Manager::update( 1, [ 'title' => 'Новое название' ] );

// Удалить запись
Arsenal_History_Manager::delete( 1 );
?>
```

## 🔒 Безопасность

- Все данные санитизированы через WordPress функции
- Все SQL запросы используют prepared statements
- Все действия защищены проверкой прав доступа (manage_options)
- Все формы защищены nonce токенами
