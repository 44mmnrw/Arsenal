## Основные переменные и их значения:

### CSS переменные (var) с HEX значениями:
- var(--red-700) = #FF1A1A

## 📊 Итоговая статистика

**Всего цветов**: 160 уникальных
- HEX: 104
- RGBA: 52
- CSS переменные (var): 26
- RGB: 3
- Комбинированные (var с fallback): 15

**Топ-5 самых используемых цветов:**
1. rgba(0, 0, 0, 0.1) - 41 раз (тени)
2. #ff1a1a - 39 раз (красный)
3. #fff + #ffffff - 58 раз совместно (белый)
4. #0a0a0a - 26 раз (черный текст)
5. var(--red-700, #ff1a1a) - 21 раз (красный переменная)
