## 🎯 Использование

### Добавить спонсора через админку:
1. Перейти: Арсенал → Спонсоры и партнеры
2. Нажать "[+ Добавить спонсора]"
3. Заполнить форму
4. Нажать "Добавить спонсора"

### Отредактировать спонсора:
1. В списке найти спонсора
2. Нажать "Редактировать"
3. Изменить данные
4. Нажать "Обновить спонсора"

### Удалить спонсора:
1. В списке найти спонсора
2. Нажать "Удалить"
3. Подтвердить удаление

### На фронтенде:
- Все изменения сразу отображаются на странице /sponsors/
- Спонсоры сортируются по order_index
- Генеральный спонсор отображается отдельно от партнеров

## 🔄 Интеграция с плагином

```php
// В админке
add_submenu_page(
    'arsenal-team',                    // Родительский пункт
    'Спонсоры и партнеры',            // Название страницы
    'Спонсоры и партнеры',            // Пункт меню
    'manage_options',                  // Права доступа
    'arsenal-sponsors',                // Slug
    array( $this, 'render_sponsors_list' ) // Callback
);

// Функция рендерит админ-страницу
public function render_sponsors_list() {
    require_once ARSENAL_TM_PLUGIN_DIR . 'admin/pages/sponsors.php';
}
```
