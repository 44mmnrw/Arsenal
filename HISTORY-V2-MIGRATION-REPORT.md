## 🔍 Структура данных (post_meta)

### Хранение в БД
```
wp_postmeta:
  post_id: <id страницы history>
  meta_key: _arsenal_history_data
  meta_value: (JSON строка)

Пример:
{
  "title": "История клуба",
  "description": "<p>...</p>",
  "scale": [...],
  "title_second": "...",
  "records": [...],
  "achievements": [...],
  "title_third": "...",
  "additional_cards": [...]
}
```

## 💻 Как использовать

### Получить историю в коде
```php
$history = Arsenal_History_Manager::get_history();

// $history содержит:
// - $history['title']
// - $history['description']
// - $history['scale'] (массив)
// - $history['title_second']
// - $history['records'] (массив)
// - $history['achievements'] (массив)
// - $history['title_third']
// - $history['additional_cards'] (массив)
```

### Сохранить историю
```php
$data = [
    'title' => 'История клуба',
    'description' => 'Текст...',
    'scale' => json_encode([...]),
    // ... остальные поля
];

Arsenal_History_Manager::save_history( $data );
```
